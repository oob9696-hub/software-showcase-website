# NexaFlow 软件展示网站

这是一个基于纯 HTML/CSS/JavaScript 的现代软件展示型 landing page，适合用于 SaaS、企业工具、产品介绍页等场景。

## 目录结构

- `index.html`：页面结构
- `styles.css`：页面样式
- `script.js`：交互脚本

## 运行方式

直接在浏览器中打开 `index.html` 即可查看效果。

## 特色

- 响应式布局
- 现代科技风 UI
- SaaS 产品主页结构
- 价格区、功能区、评价区、CTA 区

## 自定义说明

你可以直接编辑 `index.html` 中的内容和 `styles.css` 中的主题色，以便替换成你的品牌名称、产品信息与配色。

## 部署

如果你需要部署到 GitHub Pages，可以在仓库中开启 Pages，并选择根目录即可。
